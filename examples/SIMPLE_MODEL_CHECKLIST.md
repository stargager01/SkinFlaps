## 3. 파라미터 수정

### 3.1 설정 파일 구조 이해

SMD 파일 (`*.smd`)은 JSON 형식으로 다음 섹션을 포함합니다:

```json
{
    "dynamicObjects": { ... },      // 물리 시뮬레이션 대상 모델
    "staticObjects": { ... },       // 충돌 전용 정적 모델
    "textureFiles": { ... },        // 텍스처 이미지 매핑
    "tetrahedralProperties": { ... }, // 물리 파라미터 (핵심!)
    "tetrahedralSubsets": { ... },  // 특정 영역 파라미터 오버라이드
    "fixedCollisionSets": { ... }   // 고정 충돌 영역
}
```

### 3.2 핵심 파라미터 설명

| 파라미터 | 설명 | 기본값 | 권장 범위 |
|----------|------|--------|-----------|
| `minStrain` | 최소 변형률 (압축) | 0.85 | 0.7 ~ 0.95 |
| `maxStrain` | 최대 변형률 (신장) | 1.20 | 1.05 ~ 1.35 |
| `lowTetWeight` | 저강성 사면체 가중치 | 400.0 | 200 ~ 800 |
| `highTetWeight` | 고강성 사면체 가중치 | 800.0 | 500 ~ 2000 |
| `collisionWeight` | 충돌 반응 강도 | 30000.0 | 10000 ~ 60000 |
| `selfCollisionWeight` | 자기 충돌 강도 | 60000.0 | 30000 ~ 100000 |
| `fixedWeight` | 고정점 구속 강도 | 8000.0 | 5000 ~ 20000 |
| `hookWeight` | 후크(잡는 점) 강도 | 800.0 | 500 ~ 2000 |
| `sutureWeight` | 봉합 강도 | 1500.0 | 1000 ~ 4000 |
| `nTetSizeLevels` | 다중 해상도 레벨 수 | 3 | 2 ~ 5 |
