## 1. 시작하기

### 1.1 프로그램 실행
1. SkinFlaps 실행 파일을 더블클릭합니다
2. 메인 창이 열리면 `File` → `Load model` 선택
3. `.smd` 파일을 선택하여 모델을 불러옵니다

### 1.2 지원 파일 형식
| 확장자 | 설명 |
|--------|------|
| `.smd` | 모델 설정 파일 (Scene Model Definition) |
| `.hst` | 수술 기록 파일 (History) |
| `.obj` | 3D 메쉬 파일 (출력용) |

## 3. 기본 조작법

### 3.1 마우스 조작

| 동작 | 기능 |
|------|------|
| **왼쪽 버튼 드래그** | 모델 회전 |
| **오른쪽 버튼 클릭** | 수술 도구 적용 (도구 선택 시) |
| **오른쪽 버튼 드래그** | 훅/봉합 드래그 (View 모드) |
| **마우스 휠** | 줌 인/아웃 (기본 설정) |
| **Ctrl + 오른쪽 클릭** | 특수 기능 (도구별 상이) |
| **Shift + 오른쪽 클릭** | 특수 기능 (도구별 상이) |

### 3.2 키보드 단축키

| 키 | 기능 |
|----|------|
| **Enter** | 현재 작업 완료/확정 |
| **Delete** | 선택한 객체 삭제 / 마지막 점 삭제 |

### 3.3 줌 설정 변경
`View` → `Zoom control`에서 선택:
- **Mouse Wheel**: 마우스 휠로 줌 (기본값)
- **Right Mouse**: 오른쪽 마우스 드래그로 줌

## 4. 수술 도구 상세 설명

### 4.1 View (뷰어 모드)
**목적**: 모델 탐색 및 객체 선택

**사용법**:
- 왼쪽 마우스로 모델 회전
- 오른쪽 클릭으로 훅(H_) 또는 봉합(S_) 선택
- 선택된 훅/봉합은 드래그하여 이동 가능

**팁**:
- 수술 작업 사이에 View 모드로 전환하여 결과 확인
- 훅 선택 후 Delete 키로 삭제 가능

---

### 4.2 Hook (훅 도구)
**목적**: 조직을 잡아당기거나 고정하는 훅 생성

**사용법**:
1. Hook 도구 선택
2. 피부 표면에서 오른쪽 클릭
3. 훅이 생성되고 자동으로 선택됨

**Ctrl/Shift + 클릭**: 없음

**Power Hooks 옵션**:
- `Tools` → `Use Power Hooks` 체크
- 더 강한 힘으로 조직을 당길 수 있음

**훅 조작**:
- View 모드에서 훅 선택 후 드래그하여 이동
- Delete 키로 선택된 훅 삭제

---

### 4.3 Knife (절개 도구)
**목적**: 피부에 절개선 생성

**사용법**:
1. Knife 도구 선택
2. 피부 표면(Material 2)에서 시작점 오른쪽 클릭
3. 경로를 따라 추가 점들 클릭
4. 마지막 점에서 **Enter** 키로 절개 완료

**Ctrl/Shift + 클릭**:
- 기존 절개선에 T자 연결 (T-in/T-out)
- 절개선을 기존 절개에 연결할 때 사용

**Delete 키**: 마지막 점 삭제

**주의사항**:
- 피부 표면(Material 2)에서만 절개 가능
- 최소 2개 이상의 점 필요
- 3개 이상의 점이 있으면 시작점으로 돌아가 닫힌 절개 가능

---

### 4.4 Undermine (박리 도구)
**목적**: 피부를 아래 조직에서 분리

**사용법**:
1. Undermine 도구 선택
2. 박리할 피부 영역에서 오른쪽 클릭
3. 삼각형이 선택되어 박리 표시됨
4. 여러 삼각형을 클릭하여 박리 영역 확장
5. **Enter** 키로 박리 완료

**Ctrl/Shift + 클릭**:
- 절개선 연결 없이 독립적 박리
- 기본적으로는 절개선과 연결됨

**Delete 키**: 박리 영역 초기화

**주의사항**:
- 절개(Knife) 후에 수행해야 효과적
- 피부 표면(Material 2)에서만 가능

---

### 4.5 Suture (봉합 도구)
**목적**: 절개된 조직 가장자리 연결

**사용법**:
1. Suture 도구 선택
2. 첫 번째 봉합점에서 오른쪽 클릭
3. 두 번째 봉합점으로 드래그하여 놓기
4. 봉합이 생성되어 두 점을 연결

**Ctrl/Shift + 클릭**:
- 자동 봉합선 생성
- 이전 봉합점에서 현재 점까지 자동으로 여러 봉합 생성
- 피부/점막 가장자리에서만 사용 가능

**봉합 삭제**:
- View 모드에서 봉합 선택 후 Delete 키

**주의사항**:
- 절개(Knife) 후에 수행
- 절개 가장자리(Material 3) 또는 피부 표면(Material 2)에서 시작

---

### 4.6 Excise (절제 도구)
**목적**: 조직 조각 완전 제거

**사용법**:
1. Excise 도구 선택
2. 제거할 조직 영역에서 오른쪽 클릭
3. 해당 영역이 즉시 제거됨

**주의사항**:
- 절개 가장자리(Material 3)나 절단된 근육(Material 6)에서는 불가
- 닫힌 절개선으로 둘러싸인 영역에서 사용
- 실행 취소 불가능하므로 신중하게 사용

---

### 4.7 Deep Cut (심부 절개 도구)
**목적**: 피부 아래 깊은 층까지 절개

**사용법**:
1. Deep Cut 도구 선택
2. 시작점에서 오른쪽 클릭
3. 경로를 따라 점들 클릭
4. **Enter** 키로 심부 절개 완료

**Ctrl/Shift + 클릭**:
- 열린 끝점 (closed end = false)
- 기본적으로는 닫힌 끝점

**Delete 키**: 마지막 점 삭제

**주의사항**:
- 박리되지 않은 피부 표면(Material 2) 또는 심부 층(Material 5)에서만 가능
- 절개 및 박리 후에 수행

---

### 4.8 Periosteal (골막 박리 도구)
**목적**: 골막층 박리 (가장 깊은 층)

**사용법**:
1. Periosteal 도구 선택
2. 골막 영역에서 오른쪽 클릭
3. 박리할 삼각형들 선택
4. **Enter** 키로 골막 박리 완료

**Ctrl/Shift + 클릭**:
- 절개선 연결 없이 독립적 박리

**주의사항**:
- 심부 절개(Deep Cut) 후에 수행
- 골막 박리 후에는 취소 불가

## 5. 수술 워크플로우

### 5.1 기본 피판 수술 순서

```
1. 모델 로드
      ↓
2. Hook으로 시야 확보 (선택사항)
      ↓
3. Knife로 절개선 디자인
      ↓
4. Undermine으로 피부 박리
      ↓
5. Deep Cut으로 심부 절개 (필요시)
      ↓
6. Periosteal로 골막 박리 (필요시)
      ↓
7. Excise로 병변 제거 (필요시)
      ↓
8. Suture로 봉합
      ↓
9. 결과 확인 및 저장
```

### 5.2 간단한 절개-봉합 예제

1. **모델 로드**: `File` → `Load model` → `simple_circle.smd`

2. **절개 생성**:
   - Knife 도구 선택
   - 피부 표면에 3-4개 점 클릭
   - Enter 키로 완료

3. **피부 박리**:
   - Undermine 도구 선택
   - 절개 양쪽의 피부 클릭
   - Enter 키로 완료

4. **봉합**:
   - Suture 도구 선택
   - 절개 한쪽 가장자리 클릭
   - 반대쪽 가장자리로 드래그

5. **결과 확인**: View 모드로 전환하여 확인

## 6. 파일 관리

### 6.1 모델 파일 로드
`File` → `Load model`
- `.smd` 파일 선택
- 모델이 3D 뷰포트에 표시됨

### 6.2 수술 기록 저장
`File` → `Save history`
- `.hst` 파일로 저장
- 모든 수술 작업이 기록됨

### 6.3 수술 기록 재생
`File` → `Load history`
- 저장된 `.hst` 파일 선택
- **NEXT** 버튼으로 단계별 재생

### 6.4 Blend Shape 출력
`File` → `Output blend shape file`
- 현재 상태를 `.obj` 파일로 내보내기
- 다른 3D 소프트웨어에서 사용 가능

## 7. 고급 기능

### 7.1 물리 시뮬레이션 보기
`View` → `View Physics`
- 내부 테트라헤드랄 격자 표시
- 물리 시뮬레이션 디버깅에 유용

### 7.2 표면 보기 토글
`View` → `View Surface`
- 표면 메쉬 표시/숨김

### 7.3 물리 일시정지
`Tools` → `Pause physics`
- 물리 시뮬레이션 일시 중지
- 복잡한 작업 시 성능 향상

### 7.4 봉합 승격
`Tools` → `Promote sutures`
- 자동 생성된 임시 봉합을 영구 봉합으로 변환

## 8. 문제 해결

### 8.1 일반적인 오류 메시지

| 오류 메시지 | 원인 | 해결책 |
|-------------|------|--------|
| "The model file did not load successfully" | SMD 파일 형식 오류 | SMD 파일 구문 확인 |
| "Model is not a closed manifold surface" | 메쉬가 닫힌 볼륨이 아님 | OBJ 파일 수정 |
| "Couldn't create the initial physics lattice" | 메쉬 geometry 오류 | 단순한 형태로 모델 수정 |
| "surfacePath() call does not have a valid starting triangle" | 상단 표면 삼각형 부족 | 상단 표면 세분화 |
| "Can only incise from top side of skin" | 잘못된 표면에서 절개 시도 | Material 2 표면 선택 |
| "Can only undermine from top side of skin" | 잘못된 표면에서 박리 시도 | Material 2 표면 선택 |

### 8.2 프로그램이 멈춘 경우
- 물리 시뮬레이션이 진행 중일 수 있음
- 모래시계 커서가 사라질 때까지 대기
- 복잡한 작업은 시간이 걸릴 수 있음

### 8.3 수술 작업이 적용되지 않는 경우
1. 올바른 도구가 선택되었는지 확인
2. 올바른 표면(Material)에서 클릭했는지 확인
3. 필요한 선행 작업(절개→박리→봉합)이 완료되었는지 확인

### 8.4 훅이나 봉합이 선택되지 않는 경우
- View 모드로 전환 확인
- 객체 위에서 정확히 클릭

## 참고 자료

### Material 번호 참조
| Material | 설명 | 색상 |
|----------|------|------|
| 2 | 피부 표면 (Skin) | 피부색 |
| 3 | 절개 가장자리 (Incision edge) | 빨간색 |
| 5 | 심부 층 (Deep bed) | 분홍색 |
| 6 | 절단된 근육 (Cut muscle) | 어두운 빨강 |
| 7 | 골막 (Periosteal) - 고정됨 | 노란색 |
| 8 | 박리된 골막 | 밝은 노랑 |

### 유용한 팁
1. **자주 저장하기**: 복잡한 수술 전에 항상 기록 저장
2. **단계별 접근**: 한 번에 하나의 도구만 사용
3. **View 모드 활용**: 작업 사이에 결과 확인
4. **작은 단계로**: 큰 절개보다 여러 작은 절개가 안전
